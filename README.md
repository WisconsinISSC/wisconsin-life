# Wisconsin Life

Wisconsin Life is a web-based information resource developed by the
Wisconsin International Student Service Center (WISSC).

The goal of this project is to provide practical information and life tips
for international students, scholars, and newcomers living in Wisconsin.

## Website

Live website:

https://wisconsinissc.github.io/wisconsin-life/

## Topics

Planned content includes:

- Getting Started in Wisconsin
- Housing
- Transportation and DMV
- Healthcare
- Food and Shopping
- Wisconsin Winter
- Campus Life
- Things to Do
- Local Resources
- Frequently Asked Questions

## Project Status

This project is currently in early development.

The first version focuses on providing useful informational content.
Additional features may be added in the future based on user needs.
